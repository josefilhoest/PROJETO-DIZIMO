Sistema web desenvolvido para auxiliar no controle mensal de dízimos da **Paróquia Nossa Senhora da Penha - Sucatinga**.

O projeto permite cadastrar, editar, excluir e organizar dizimistas por folhas, registrar valores, calcular totais automaticamente e gerar uma ficha preparada para impressão em formato A4.
